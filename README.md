Brechó Moda Renascida

Brechó Moda Renascida é um e-commerce simples desenvolvido em Django, com foco em moda sustentável. O projeto exibe produtos de forma prática, permite busca por nome e direciona o cliente para contato via WhatsApp.

🔹 Funcionalidades

Exibição de produtos com imagens, descrição e preço

Busca por nome de produto

Redirecionamento direto para WhatsApp

Paginação para navegação entre produtos

Layout responsivo para dispositivos móveis e desktops

Página "Sobre Nós" com a proposta do brechó


💻 Tecnologias

Backend: Django

Frontend: HTML5, CSS3

Banco de Dados: SQLite (para desenvolvimento)
